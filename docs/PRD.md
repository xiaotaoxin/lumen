# Lumen 产品需求文档（PRD）

> 阶段：v1.0-preview · 演示版本（前端 + 真 provider 适配器 + Mock 后端兜底）
> 最近更新：2026-05-07

---

## 1. 产品定位

**Lumen** 是一个面向创作者的 **图像 / 视频 / 灵感画布** 一体化生成工作台。一句话定义：

> **聚合多家主流模型，让从一句话到一帧光、再从一帧光到一段动的整条创作链路在一处完成。**

差异化主张：
- **聚合而非单一**：在同一画布 / 同一对话流里横向比较多家模型
- **从想法到资产**：支持「文字 → 图」「图 → 视频」「图 → 图变体」的多步骤工作流，不止单点生成
- **创作者友好**：编辑型排版、节制动效、暗色优先；不堆"AI 科技感"装饰

---

## 2. 目标用户

| 角色 | 占比 | 主要诉求 |
| --- | --- | --- |
| **学生 / 自由创作者** | 60% | 低门槛体验多家模型、收集灵感素材、做小型片段（短视频 / 海报 / 概念稿） |
| **设计师 / 内容运营** | 25% | 围绕角色 / 品牌的复用素材库、批量出图、风格一致 |
| **小型工作室主理人** | 10% | 给团队成员开放权限、看团队消耗与活跃 |
| **管理员**（兼角色） | 5% | 配置可用模型、管理用户与申请 |

非目标用户：企业级 SaaS 客户（合规 / SLA / 多租户暂不覆盖）。

## 3. 核心场景

### 3.1 单条文生图（最高频）
> 用户：写一句"夜里下雨的东京街头" → 选 Lumen Image v1 → 生成 1 张方图 → 满意 → 收藏。
- 入口：`/app/text-to-image`
- 关键操作：写提示词、选模型、按发送、看结果、收藏 / 重跑 / 删除

### 3.2 多步骤工作流（节点流画布）
> 用户：先生成一张古风寺庙的图 → 满意 → 把它送到视频节点 → 加镜头描述 → 生成 5 秒视频。
- 入口：`/app/canvas`（新建画布 → 选「节点流」）
- 关键操作：双击空白添加节点 / 模板、连线触发、节点选中浮动工具栏

### 3.3 灵感板收集（自由画布）
> 用户：从其它工具截图 → Ctrl+V 粘贴到 Lumen 的自由画布 → 拖动、缩放、对齐 → 配上文字注释。
- 入口：`/app/canvas` → 「自由画布」
- 关键操作：上传 / 拖入 / 粘贴；空格平移；4 角缩放；对齐参考线

### 3.4 主体复用
> 用户：定义主角"Lina（短发亚裔少女，淡灰色风衣）"→ 后续每次出图直接 `@Lina` → 风格保持一致。
- 入口：`/app/subjects` 新建；任何 prompt 中输入 `@`
- 关键操作：管理主体、@ 引用

### 3.5 管理员配置模型
> 管理员：内部部署了 ComfyUI / 申请到 OpenAI key → 在 `/admin/models` 添加自定义模型 → 启用 → 用户立即看到并使用。
- 入口：`/admin/models`
- 关键操作：新增、填配置、测试调用（规划中）、启用

### 3.6 管理员审核与运营
- 注册审核：`/admin/registrations`
- 用户管理：`/admin/users`
- 数据看板：`/admin/analytics`

### 4.3 图生视频工作台 `/app/image-to-video`

### 4.12 模型目录
- **内置 mock 卡片已清空**（`BUILT_IN_MODELS = []`）：避免演示卡片与真配置混淆

## 5. 关键用户故事 + 验收

### US-1：新用户首次创作
**As** 一名首次访问的用户
**I want to** 完成注册并产出第一张图
**So that** 我能立刻判断这个工具是否值得继续用

**验收**：
1. 在 `/register` 提交账号密码，看到「等待审核」状态页
2. 管理员审核通过后能登录
3. 登录后默认落到 `/app/text-to-image`
4. 写一句话 + 点发送，10 秒内看到生成结果
5. 该结果出现在 `/app/history`

### US-2：复用主体一致风格
**As** 一名做角色设定的设计师
**I want to** 让生成的图保持同一角色的视觉特征
**So that** 我能快速产出系列素材

**验收**：
1. 在 `/app/subjects` 新建主体 `Lina` + 描述
2. 回到 `/app/text-to-image`，写「@Lina 在咖啡馆里」
3. `@` 处出现候选 popup，回车选中
4. 提交后侧栏 session 标题 / 历史卡片中 prompt 显示原文（不被展开污染）
5. 生成的图明显带有主体描述的视觉特征（mock 阶段结果哈希会不同）

### US-3：跨节点延展工作流
**As** 一名做短视频的内容运营
**I want to** 把生成的静帧延展成动态镜头
**So that** 我不需要在两个工具间切换

**验收**：
1. `/app/canvas` 新建「节点流画布」
2. 双击空白选「图生视频」模板，自动得到「图节点 → 视频节点」连好
3. 在图节点写 prompt + 生成
4. 图节点完成 → 视频节点自动开始生成（前提：视频节点已写 prompt）
5. 两个节点结果都正确显示

### US-4：管理员加 OpenAI key 让用户使用 DALL·E
**As** 一名管理员
**I want to** 把团队的 OpenAI key 配进系统
**So that** 普通用户不用各自申请就能用

**验收**：
1. `/admin/models` 点「新增自定义模型」
2. 选 Provider Type = OpenAI（**待真做**）
3. 填 key + Model ID（dall-e-3）
4. 点「测试调用」（**待真做**），1-15 秒内看到 ✓ 或 ✕ 错误码
5. 启用后切到 `/app/text-to-image`，模型选择器底部出现这个新模型
6. 选中 → 真发请求 → 真出图（**待真做**）

> ⚠️ 当前阶段 1-2 步已可走通；3-6 步是 mock，等真模型 adapter 接入。

## 7. 不在范围（明确不做）

- **企业级**：SSO / SAML / 审计日志 / SLA
- **多租户**：组织 / 团队 / 工作区 ACL
- **复杂权限**：仅"用户 / 管理员"两层，不引入角色矩阵
- **真实视频流编辑**：非视频 NLE 工具
- **3D 内容生成**：暂不在产品范围
- **聊天机器人 / 多模态对话**：Lumen 是创作工具，不是 chatbot

## 8. 关键产品决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 默认主题 | 暗色 | 创作类工具的主流期待 + 我们的暖琥珀 brand 在暗色下更出彩 |
| 移动端 | 暂不做 | 创作场景以桌面为主；最低支持宽度 1280px |
| 国际化 | 中文优先 | 目标用户主要是中文创作者；英文待后续 |
| 视觉参考 | 借鉴 + 自创 | 商业产品复刻有 IP / 不正当竞争风险，统一走"借鉴功能、自创视觉"的口径 |
| 生成结果保存策略 | 浏览器 localStorage（mock 阶段）→ OSS（接后端） | 演示零运维 |
| 模型目录 | 内置 + 管理员可扩 | 默认开箱即用，团队按需扩展 |
| Inline 编辑 vs 居中 composer | 工作台用居中 chat-style，画布用 inline 节点 | 两种创作姿势对应不同形态 |
| 画布双形态 | 节点流 + 自由画布 | 工作流和灵感板是两种场景，硬塞一个会两边都妥协 |

## 9. 度量指标（接真后端后启用）

| 指标 | 含义 | 健康阈值 |
| --- | --- | --- |
| DAU / WAU | 活跃用户 | 目标场景下基线 |
| 平均生成数 / 用户 / 周 | 黏性 | > 5 |
| 单次会话平均生成数 | 探索深度 | > 3 |
| 收藏率 | 满意度 | > 15% |
| 失败率 | 健壮性 | < 5% |
| p95 生成耗时 | 性能 | < 15s（图）、< 60s（视频） |
| 每用户每月平均消耗 | 成本控制 | 按定价反算 |
